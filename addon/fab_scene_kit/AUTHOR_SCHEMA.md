# FAB asset brief / recipe v1

`author_spec.py` is the authoritative pure-stdlib validator. `data/author_examples/ammr_example.json` is a complete synthetic 38-component example. Both measured briefs and returned modeling recipes use the same schema. Imported data is never executed.

## Coordinates

All distances in serialized data are **meters**, independent of the source Blender scene units. +Z is up, -Y is front, +X is right. `position` and `rotation` are absolute in asset space. Rotations are XYZ Euler degrees (Blender Euler XYZ). Shape points are local to their component. Joint center and unit direction are in asset space. `parent` is semantic hierarchy, never an additional transform.

Local source object pointers, source paths, source frame origin/orientation and BU scale remain in the local working `.blend`. Same-ID reimport retains those bindings. A different asset ID clears them. Frame setup is required before measuring a different source. Source object names are not automatically exported; entered component names and notes are included verbatim.

## Required root keys

| Key | Value |
|---|---|
| schema / schema_version | `fab.asset-brief` / `1` |
| id | Stable identifier, normally `asset_` plus an opaque identifier. Preserve on revision. Use the `asset_` prefix for .blend round trips. |
| name / type | Display name; `EQUIPMENT`, `AMR`, `AMMR`, `ARM`, `HUMANOID`, `OHT` |
| units | `m` |
| coordinates | `{ "up":"+Z", "front":"-Y", "rotations":"XYZ degrees", "part_transforms":"asset_absolute" }` |
| style | `{ "profile":"fab_scene_kit", "theme":"LIGHT" }`, or DARK |
| features / omit | Descriptions of identity and simplification intent |
| parts | Up to 256 component objects |

## Required component keys

`id`, `name`, `role`, `parent` (empty string for root), `enabled` (bool), `configured` (bool), `source` (`manual`, `selection`, `profile`, `path`), `shape`, `position[3]`, `rotation[3]`, `size[3]`, `material`, `bevel`, `taper`, `radius`, `points`, `joint`, `notes`.

- Use stable unique part IDs; no parent cycles. Unknown/missing fields are rejected.
- `size` contains positive full local dimensions. Cylinder runs along local Z; its X/Y dimensions define an elliptical cross section. Ellipsoid uses the three diameters. Taper uses `taper` as top/bottom width ratio.
- `bevel` is a fraction of the smallest size dimension, from 0 to 0.2. `taper` is 0.05–2. `radius` is PATH radius in meters.
- PROFILE: simple closed local XY polygon, no repeated closing point; extruded +/- Size Z/2. Concave outlines accepted; holes, self-intersections and multiple outlines rejected.
- PATH: ordered local XYZ polyline. Repeat first point at end to close. Maximum 256 serialized points.
- `joint`: `{ "enabled":false, "center":[0,0,0], "axis":[0,0,1] }`. Enabled axes must have unit length. Metadata only, no rig.
- Material roles: `navy`, `mint`, `ice`, `ivory`, `gold`, `blue`, `white`, `steel`, `joint`, `display`, `red`.
- Roles and default shapes are listed in `author_spec.ROLES`. Shape choice and functional role are independent.
- `configured=false` is permitted for draft export but prevents generation if the component is enabled. Recommended missing roles are warnings.
- Maximum JSON is 2 MB UTF-8, no duplicate keys or non-finite numbers. Numeric limits protect Blender from unusable geometry; there is no deliberate rounding for confidentiality.

## Returning a finished asset

Prefer a revised JSON recipe for primitives, outlines and paths. Preserve asset and part IDs to retain local bindings. Returned recipes should include intended new functional details explicitly; measure-only bounding boxes do not infer them.

For custom modeled geometry use an individual FAB Author library `.blend` generated by `author_model.save_library`, then edit its asset collection in Blender and preserve the embedded `fab_author_brief`, asset tags, floor origin and dimension metadata. The file must contain exactly one collection named `FAB_asset_*`. Imports accept static meshes/curves/text, up to 1,024 objects, no external links, constraints, drivers or arbitrary modifiers; allowed modifiers are Bevel, Weighted Normal, Subdivision, Solidify, Triangulate. Maximum file size is 100 MB. Update `fab_size` and `instance_offset` if editing changes the outer bounds.

The library import preserves actual geometry. The UI's **Save Asset + Thumbnail** instead rebuilds from the current recipe. Local catalog IDs are prefixed `local.`. Revisions use distinct files so older placed instances remain stable.
