# Quick Capture — FAB Scene Kit 0.4.1

## 가장 짧은 사용 순서

1. Blender에서 모델을 불러오고 Object Mode에서 전체 모델을 선택합니다. Outliner에서 공통 부모를 선택해도 됩니다. 부모를 선택하면 숨겨진 자식까지 포함됩니다. 불필요한 바닥·주변 설비·내부 조립품을 제외하려면 원하는 메시들만 선택하세요.
2. N → FAB Author → Quick Capture에서 **Type**과 **Key features**를 입력합니다. 예: `낮은 이동 베이스, 뒤쪽 관절 로봇팔, 두 손가락 그리퍼, 전면 원형 스캐너`. 특징은 240자까지입니다.
3. **Capture Selection**을 누릅니다. 파란 형상 가이드가 원본 옆에 나타납니다. 크기, 방향, 주요 돌출부가 맞는지 확인합니다. 원본 선택은 유지됩니다.
4. **Copy Text (1000 max)**로 복사하거나 **Save Text...**로 저장합니다. 복사된 한 줄 전체를 모델 제작 담당자에게 전달합니다. 이 애드온이 외부에 자동 전송하지는 않습니다.

## 화면에서 확인할 것

`938 / 1000 characters`처럼 실제 전송 길이를 표시합니다. 타입·특징·치수·형상 데이터와 JSON 기호를 모두 포함합니다. 길이를 넘기면 중요도가 낮은 형상부터 제외합니다. 특징 문장은 임의로 자르지 않습니다. 한글도 사용할 수 있으며 이모지는 보수적으로 2자로 계산합니다. UTF-8 바이트 제한과는 다릅니다. 1000바이트 제한 환경에는 이 형식을 그대로 적용할 수 없습니다.

Size는 미터 기준 전체 외형입니다. 일반 로봇이 수백 미터로 표시되면 **Units / front direction → Custom → Meters / unit = 0.001** 등을 사용해 단위를 맞추고 다시 캡처합니다. 기본값은 Scene units입니다. FBX가 이미 미터로 변환되어 있다면 다시 0.001을 적용하지 마세요.

기본 앞쪽은 월드 -Y, 위쪽은 +Z입니다. 모델이 다른 방향으로 누워 있거나 돌아가 있으면 **Reference rotation**으로 모델의 기준 프레임을 맞춥니다. 자동으로 장비의 앞면을 알아내지는 않습니다. 원본 모델을 회전시키는 대신 측정 프레임만 바꿉니다.

**Select Shape Guide**로 파란 가이드를 선택할 수 있습니다. 가이드를 선택한 상태로 재캡처하면 거절됩니다. 다시 원본을 선택하세요. 반복 캡처에서는 이전 가이드를 숨기고 이전 텍스트를 Blender Text 블록에 보존합니다. 새 파일로 내보내기는 직접 Save Text를 눌렀을 때만 수행합니다.

## 이 텍스트가 전달하는 것

전체 치수, 주요 외형의 중심·크기·방향, 단순 원통 판정, 직접 입력한 타입과 특징을 전달합니다. 볼트 같은 작은 덩어리는 우선 제외합니다. 원본 오브젝트 이름·파일 경로·메시 정점 목록·이미지를 넣지 않습니다. 새 패키지 설치나 네트워크 연결 없이 Blender에 포함된 Python과 NumPy를 사용합니다.

파란 가이드는 완성 에셋이 아니라 **형상 요약**입니다. 색상·재질·세부 기능은 아직 해석하지 않습니다. 숨겨진 관절, 구멍, 창, 얇은 케이블, 복잡한 자유곡면은 누락되거나 뭉개질 수 있습니다. 중요한 특징은 Key features에 적으세요. 정보가 부족하면 추가 설명을 받고 FAB 디자인 언어로 다시 모델링해야 합니다.

대형 외장이 다른 중요한 부품보다 우선될 수 있습니다. 가이드에서 핵심 형태가 사라졌다면 내부 부품을 제외해 다시 캡처하거나 Advanced에서 필요한 부분을 지정합니다. 500만 evaluated vertices를 넘는 선택은 처리하지 않으며 선택을 줄이도록 안내합니다. 처리 속도는 모델 구조와 PC에 따라 달라집니다.

## 받은 결과 사용하기

**Receive a result → Paste Quick Text + Preview** 또는 **Import Quick Text...**는 FQ1 텍스트만으로 같은 파란 형상을 만듭니다. 이후 **Edit Summary in Advanced**로 편집할 수 있습니다. 이때 기존 Advanced 초안은 Text 블록에 보존됩니다. 단순 형상에는 아직 부품 역할이나 관절 연결이 지정되어 있지 않습니다.

최종 모델을 받았다면 **Receive a result → Import Finished Asset...**를 눌러 Library로 이동합니다. Local Library 폴더를 지정하고 **Import Author .blend**로 개별 에셋을 가져옵니다. FAB Kit에서 불러와 배치할 수 있습니다. 텍스트 요약 프리뷰를 저장하는 것과 최종 모델을 가져오는 것은 다른 작업입니다.

## 기존 기능과 호환

N 사이드바 탭은 기존 **FAB Kit / FAB Author** 두 개입니다. Quick Capture와 Advanced는 FAB Author 내부 모드입니다. Advanced에는 이전 Setup / Parts / Review / Library 기능이 남아 있습니다. 기존 0.4.0의 상세 JSON도 계속 사용할 수 있으며 상세 JSON에는 1000자 제한을 적용하지 않습니다. 전송 길이가 제한되면 Quick Capture의 Copy Text 또는 Save Text를 사용하세요.

Quick Capture는 시점의 스냅샷입니다. 원본 형상을 수정했으면 반드시 다시 캡처하세요. 타입·특징·단위·방향을 바꾸면 복사/내보내기가 비활성화됩니다. 기존 장면, 기본 에셋 52개와 템플릿 3개를 유지합니다.
