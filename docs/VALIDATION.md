# Validation scope

The current add-on is **FAB Scene Kit 0.4.2**, tested in Blender 4.3.0. Its source matches every file in the tested ZIP; the final checksum is in `dist/manifest.json`.

Guided Brief passed 58 checks against an actual installed ZIP: multi-root deduplication, explicit Workspace review, source exclusion, selected-only vs descendants, armature pose evaluation, rotated/mm frames, stale measurements, overlapping assignments, malformed local drafts, Unicode 1000/1001 boundaries, save/reopen and missing-source reconnection. A generic synthetic model was used; no production/company CAD was tested. The reproducible Blender test is `tools/test_guided_brief.py`; the public result is `docs/validation/guided_brief_042.json`.

Regression checks passed: 44 Quick Capture, 86 Advanced Author and 99 assembly checks. Thirty installed legacy checks cover import/export, completed-asset libraries, templates, placement and save/reopen. Bundled geometry stays at library version 0.3.0: 52 assets and three templates.

The running Blender application was updated from 0.4.1. All original scene geometry, existing Author draft and Quick text were retained, as was the external local-library preference. Actual UI interactions excluded a Workspace helper, confirmed scope, assigned only the L-shaped base mesh, measured, and copied a complete 543-character AW1 brief with clipboard readback. The saved workspace was reopened in a fresh isolated Blender process. Overall extent was 2 × 1.4 × 1.73 m; base-only extent was 2 × 1.4 × 0.35 m. No new geometry is generated by this wizard. A display-scale-dependent hint clipping issue was fixed and the final UI was inspected again.

The Guided HTML manual embeds five actual UI screenshots. Image integrity, local anchors and offline content passed static checks. Browser layout was not directly tested. A screenshot example uses a deliberately simple synthetic test model; it is not a new styled production asset.

Limits: AW1 communicates semantic intent and optional bounds/centers, not detailed topology or rigging. Collection instances are not measured; helper classification requires human review. Measurement is bounded at five million evaluated vertices. Source selection is a snapshot, so new source objects require Add Selection again. Measurements require refresh after a file is reopened. Other Blender versions and actual company import complexity remain unverified.

## Earlier versions


0.4.1 Quick Capture: 43 synthetic capture checks, 86 Author regression checks, 99 assembly checks and 30 final ZIP installation checks passed in Blender 4.3.0. Separate and joined synthetic CAD, mm/rotated frames, connected concave shapes, Unicode budgets, malformed packets, original-geometry preservation and paste placement were exercised. Actual Blender capture/copy/paste passed using a 938-character, 43-envelope AMMR guide.

Three comparison renders were preserved and inspected. Corrections addressed clipped framing, incorrect joined-shell splitting and low guide contrast. The final blue guide passed visual inspection; eight fresh-process scene checks passed. The guide is a lossy geometric summary, with no inferred semantic parts or hidden joints. Production CAD and other Blender versions were not directly tested.

The Quick Capture HTML contains two actual screenshots and one comparison render, all embedded. Images and anchors passed static validation; browser layout was not directly inspected.


The earlier 0.4.1 ZIP was also installed and tested in Blender 4.3.0 under an isolated extension namespace. Its archived SHA-256 remains in `dist/SHA256SUMS.txt`. Bundled asset geometry remains at library version 0.3.0.

Phase 2 validation: 86 authoring checks, 99 existing assembly regression checks and 19 actual ZIP installation checks. This covered rotated/mm geometry measurement, local bindings, file/text round trips, actual Edit Mode outline capture, all six types and shapes, joint data, revision preservation, returned .blend geometry, embedded thumbnails, template placement, theme changes and save/reopen. Native Windows clipboard and the four-step authoring panel were also exercised in Blender.

Three synthetic AMMR iterations were rendered and inspected. The second and third addressed sparse functional detail, excessive mint coverage and ground contact. The final scene passed ten fresh-process reopening checks and was visually accepted alongside the existing cobot/person assets. No company CAD models were used. Guided geometry capture does not imply automatic semantic CAD simplification.

The new Author HTML manual contains four actual screenshots and one rendered image. Static image integrity and internal anchors passed; it needs no JavaScript or network. Browser layout has not been directly checked. The previous assembly manual and catalog remain available at version 0.3.0.
